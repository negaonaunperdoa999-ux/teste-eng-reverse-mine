# Referências externas validadas

Todas consultadas em 2026-11-04. Conteúdo externo ≠ código da Mojang; marque `[DOC]` ao citar.

- **Tutorial: See Minecraft's code** — Minecraft Wiki: https://minecraft.wiki/w/Tutorial:See_Minecraft%27s_code
  Decompilação permitida para uso pessoal; não redistribuir fontes decompiladas nem releases derivados.
- **mcsrc.dev** — viewer web decompilado (FabricMC): https://mcsrc.dev/ · repo: https://github.com/FabricMC/mcsrc
  Versões: 1.14.4+ (Mojmap) e 26.1+ (unobfuscado). Recursos: herança, find-refs, diff, bytecode view.
- **Fabric Wiki — Reading the Minecraft source**: https://wiki.fabricmc.net/tutorial:reading_mc_code
  Entrypoints: `net.minecraft.client.main.Main` / `net.minecraft.server.Main`.
- **Minecraft Wiki — Java Edition 26.1**: https://minecraft.wiki/w/Java_Edition_26.1
  Primeira release unobfuscada; protocolo 775; dataPack 101.1; Java 25+.
- **steelmc.dev — Decompile**: https://steelmc.dev/development/decompile-minecraft/
  Comandos de decompilação direta com Vineflower para 26.1.
- **MinecraftSourcesGenerator**: https://github.com/Bram1903/MinecraftSourcesGenerator
  Pipeline local oficial deste laboratório. `listVersions` confirma: 26.1.2 unobfuscated vanilla.
- **Universal Modder**: https://github.com/rehan-remade/universal-modder (referência de skills; sem uso no pipeline).
